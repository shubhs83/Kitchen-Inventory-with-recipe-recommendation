# VEGETABLE MANAGEMENT APIs

## 1. Add Vegetable
POST http://localhost:8080/api/vegetables/add
Content-Type: application/json
{"name":"Spinach","weight":1.0,"unit":"Kg","addedDate":"2024-03-10","useBeforeDate":"2024-03-17"}

## 2. Update Vegetable
PUT http://localhost:8080/api/vegetables/update/1
Content-Type: application/json
{"name":"Spinach","weight":0.8,"unit":"Kg","addedDate":"2024-03-10","useBeforeDate":"2024-03-17"}

## 3. Delete Vegetable
DELETE http://localhost:8080/api/vegetables/delete/1

## 4. Get Vegetable by ID
GET http://localhost:8080/api/vegetables/1

## 5. Get All Vegetables
GET http://localhost:8080/api/vegetables/all

## 6. Search Vegetables by Name
GET http://localhost:8080/api/vegetables/search?name=spinach

## 7. Get Available Vegetables (Not Expired)
GET http://localhost:8080/api/vegetables/available

## 8. Get Spoiled Vegetables
GET http://localhost:8080/api/vegetables/spoiled

## 9. Mark Vegetable as Spoiled
PUT http://localhost:8080/api/vegetables/mark-spoiled/1

## 10. Remove Spoiled Vegetable
DELETE http://localhost:8080/api/vegetables/remove-spoiled/1
